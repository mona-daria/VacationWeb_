ПЛАН ОТПУСКОВ — АВТОНОМНЫЙ КОМПЛЕКТ ДЛЯ VS2019

1. Распакуйте ВЕСЬ архив, например в C:\VacationWeb. Не запускайте файлы внутри ZIP.
   Папка node_modules обязательна — все библиотеки уже находятся в ней.
2. Запустите Check-Environment.cmd. В конце должно быть PASS.
3. Откройте VacationWeb.sln в Visual Studio Community 2019 16.11.50.
4. Запустите Ctrl+F5. Затем откройте http://127.0.0.1:3080/ в браузере.
   Альтернативный запуск того же сервера: Start-Demo.cmd.
5. Учебные логины: employee, manager, manager2, hr, director.
   Учебный пароль: DemoVacation2027!
   Данные демонстрации в памяти, при остановке сбрасываются. Остановка: Ctrl+C.

НЕ НУЖНО запускать npm install или npm ci и скачивать библиотеки.
npm ci удаляет уже вложенную папку node_modules перед установкой.
Node.js 24.21.0 LTS должен быть установлен, как указано в документе программиста.
Если VS выбирает старый встроенный Node, укажите установленный node.exe в свойствах проекта.
Подробности: docs/VS2019.md.

Для рабочей PostgreSQL: docs/DATABASE.md, затем Check-Database.cmd,
Initialize-Database.cmd (первый кадровик), Start-Server.cmd.
Сначала создайте .env из шаблона и задайте свои параметры.
Для тестов: Run-Tests.cmd.
Для точного списка технологий: TECHNOLOGIES.txt и LIBRARIES.txt.
Для исправления кода: docs/DEVELOPER.md.
