# Visual Studio Community 2019 16.11.50

**Основной файл: VacationWeb.sln. Проект внутри: VacationWeb.njsproj.**
Комплект рассчитан на среду из «Данные.docx»: VS2019 16.11.50, нагрузка Node.js, .NET Framework 4.8, установленный Node.js 24.21.0 LTS.

## Первый запуск без npm
1. Распакуйте весь архив в короткий путь, например C:\VacationWeb. Папка node_modules должна находиться рядом с package.json.
2. Запустите Check-Environment.cmd: проверяются ветка Node24, версии и контрольные суммы всех библиотек. Никаких скачиваний нет.
3. Откройте VacationWeb.sln через Файл → Открыть → Проект/решение.
4. Если требуется, назначьте VacationWeb запускаемым проектом.
5. Свойства проекта: Startup file = launcher\start.js, Script arguments = --demo, Working directory = корень проекта. Node.exe path = установленный Node24 (обычно C:\Program Files\nodejs\node.exe).
6. Ctrl+F5 → откройте http://127.0.0.1:3080/. Автоматическое открытие браузера выключено, чтобы использовать точный адрес.
7. Остановка Ctrl+C. Повторный запуск не должен оставлять параллельный сервер на том же порту.

Для запуска не нужны npm install, npm ci, NuGet Restore или интернет. Библиотеки уже вложены. Если VS предлагает установку npm-пакетов, не запускайте ее: сначала выполните Check-Environment.cmd.
При отсутствии библиотек заново распакуйте архив целиком. Не переносите отдельно только .sln.

## Изменения описания проекта
Добавлен GUID расширения проекта Node.js вместе с основным типом проекта согласно формату Node.js Tools; импорт общих свойств MSBuild; метаданные Framework 4.8; выбор доступного файла targets (V2 либо прежнее имя).
Точка запуска перенесена в обычный .js с CommonJS для IDE; основной код остается .mjs.
Путь стандартной установки Node24 выбирается при наличии node.exe; нестандартный путь задайте в свойствах.
Точный текст прежней ошибки открытия неизвестен, поэтому эти исправления не объявляются доказанной причиной той ошибки.

## Если проект все же не открывается
В документе программиста нагрузка Node.js уже указана. При ошибке типа проекта или Microsoft.NodejsTools*.targets проверьте ее установку/восстановление именно для VS Community 2019, а не другой версии Visual Studio.
Пришлите полный текст ошибки и журнал вывода проекта. Само приложение можно проверить через Start-Demo.cmd.
Не менять расширение njsproj на csproj и не устанавливать неподтвержденные библиотеки.
Сама VS2019 на машине подготовки отсутствует: открытие и F5 в точной версии IDE не проверялись.

## Рабочая БД и редактирование
Настройте .env по DATABASE.md, выполните Check-Database.cmd и Initialize-Database.cmd.
Для рабочей БД аргумент запуска в VS: --postgres. Для службы на сервере: Start-Server.cmd либо node --env-file=.env server/index.mjs.
Браузерный JavaScript: public/app.js; сервер: server; схема: server/schema.sql. Карту смотрите в DEVELOPER.md.
Тесты: Run-Tests.cmd. Сборка VS не создает EXE; это исполняемый JavaScript-проект.
F5 можно проверить на вашем ПК. При несовместимости старого отладчика IDE с Node24 используйте Ctrl+F5; браузерную часть отлаживайте F12.
