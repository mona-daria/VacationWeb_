# Проверка автономного комплекта 1.2.0

Дата: 21.09.2026. Windows x64, Node.js 24.19.0.
Целевая среда по документу программиста: VS Community 2019 16.11.50, Node24.21.0, npm11.19.0, .NET Framework4.8.

## Результаты
- Проверка новой отдельной копии комплекта без ссылок на node_modules исходного проекта.
- Все 112 записей пакетов соответствуют package-lock.json.
- Совпали SHA-256 всех 2670 файлов библиотек.
- Решение ссылается на существующий .njsproj; XML корректен, все включенные исходники существуют; GUID расширения Node.js присутствует.
- Генератор CODE-MAP.html успешно создал карту 25 файлов.
- Автоматические тесты: **12 выполнено, 12 успешно, 0 ошибок**.
- Проверены права, CSRF, периоды, все пересечения, конфликт версий, руководитель → HR → директор, возврат на доработку, снимки Excel, обязательная смена временного пароля, отзыв сессий, 105 успешных входов с общего адреса.
- Запуск launcher/start.js --demo: HTTP health/config, HTML/JS/CSS и вход кадровика успешны.
- Некорректный аргумент и запуск PostgreSQL без .env завершаются с понятным сообщением и ненулевым кодом.
- При проверках команды npm install/npm ci не запускались, библиотеки из интернета не скачивались.

## Ограничения проверки
Visual Studio 2019 здесь отсутствует. Фактическую загрузку проекта, Ctrl+F5/F5 в версии 16.11.50 необходимо проверить у программиста.
Точная Node.js24.21.0 здесь не установлена; проверена 24.19.0 той же ветки LTS. Целевая версия указана в TECHNOLOGIES.txt.
Текст прежней ошибки открытия .sln не предоставлен; в «Данные.docx» описана недоступность скачивания npm-библиотек. Причина прежнего отказа IDE не установлена.
Тесты выполнялись с PGlite; корпоративные PostgreSQL, TLS, HTTPS-прокси, службу, восстановление резервной копии и нагрузку проверяют на целевой инфраструктуре по ACCEPTANCE.md.
