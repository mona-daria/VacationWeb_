2. ЯЗЫКИ ПРИЛОЖЕНИЯ
Сервер: JavaScript, модули ECMAScript (.mjs); используется синтаксис ES2022 и API Node.js 24.
Браузер: JavaScript (ES2022), HTML5, CSS (современные CSS-модули, обычно называемые CSS3).
База данных: SQL диалекта PostgreSQL, включая JSONB.
Точка запуска VS2019: JavaScript в режиме CommonJS (launcher/start.js).
Сценарии Windows: язык командных файлов CMD (.cmd).
Описание проекта: MSBuild XML (.njsproj), текстовое решение Visual Studio (.sln).
Настройки: JSON, переменные окружения в .env.
Код C#, ASP.NET, TypeScript, React, Vue, Angular, Express и ORM не используется.
.NET Framework не является средой исполнения веб-сервера; он нужен Visual Studio.
TargetFrameworkVersion v4.8 в проекте — метаданные инструментария VS, не перевод приложения на .NET.

3. СРЕДА ИСПОЛНЕНИЯ
Целевая версия Node.js: 24.21.0 LTS, как у программиста.
Совместимая ветка в package.json: >=24 <25.
Проверка на машине подготовки выполнена Node.js 24.19.0; точная версия 24.21.0 здесь не установлена.
npm 11.19.0 указан как установленный у получателя. Для открытия, запуска и тестов этого комплекта npm не нужен.
Комплект содержит node_modules. Не запускайте npm ci: эта команда удаляет готовые библиотеки перед установкой.
Node.exe и Visual Studio не вложены в архив — они уже установлены у получателя.

5. ДОПОЛНИТЕЛЬНЫЕ ТЕХНОЛОГИИ
Встроенный HTTP-сервер Node (node:http); HTTPS завершается корпоративным обратным прокси.
API JSON по HTTP; серверные сессии, HttpOnly/SameSite/Secure cookie, CSRF-токены.
Пароли: scrypt с солью; хеш токена сессии: SHA-256; случайные значения node:crypto.
PostgreSQL: параметризованные SQL-запросы, транзакции, блокировка плана FOR UPDATE,
внешние ключи, аудит, снимки плана в JSONB, TLS с проверкой сертификата.
Приложение не фиксирует версию сервера PostgreSQL; ее не сообщили. Совместимость,
права и TLS нужно проверить на корпоративном сервере. PGlite не заменяет эту приемку.
Экспорт XLSX (Office Open XML/ZIP) через ExcelJS.
Тесты: встроенные node:test и node:assert.
Файлы/пути/URL/процессы: встроенные модули Node; отдельная установка не требуется.
Для рабочего доступа: DNS-имя, сертификат HTTPS, обратный прокси (например IIS/nginx),
служба запуска Node, резервное копирование PostgreSQL. Это инфраструктура организации.
На ПК сотрудников нужен только современный браузер.
