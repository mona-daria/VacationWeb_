# Версия 1.2.0 — автономная передача для VS2019

Включены все 112 записей npm-библиотек из lock-файла с транзитивными зависимостями.
Добавлены контрольные суммы и диагностика, запуск/тесты/операции БД без npm.
Исправлен формат Node-проекта: GUID расширения, Common.props, выбор targets, метаданные Framework4.8.
Точка запуска для IDE — launcher/start.js в режиме CommonJS.
Добавлены обязательный TECHNOLOGIES.txt, LIBRARIES.txt и инструкции по среде программиста.
Правила отпусков, схема БД и API не менялись относительно 1.1.0.
Миграция данных при замене кода с 1.1.0 не требуется. Сохраните свой .env и резервную копию БД.
